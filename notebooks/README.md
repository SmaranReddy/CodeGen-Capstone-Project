# notebooks/

Exploratory analysis and prototyping notebooks.

- Prefix notebooks by week/topic (e.g., `w1_spider_exploration.ipynb`).
- Notebooks are for exploration only — promote reusable code into `src/`
  and runnable entry points into `scripts/`.
- Gitignore excludes `.ipynb_checkpoints/`; commit notebooks only when they
  are cleaned up and contain no secrets or dataset dumps.
